Pendapatan (USD)Unduhan

Angka dari dasbor kontributor saya sendiri, hasil portofolio pribadi di satu platform dan bukan jaminan penghasilan. Angka pada gambar kecil adalah jumlah unduhan tiap aset.

Cara kerjanya, 3 langkah

Dari ide sampai siap unggah ke platform microstock.

Buat prompt

Pilih gambar referensi sebagai inspirasi gaya, lalu ZK Prompt mengubahnya jadi prompt yang mendekati aslinya. Bisa juga bertanya ke AI favorit Anda.

Generate di ZK Vector

Tempel prompt ke ZK Vector. Generate satu per satu atau sekaligus (batch), hasilnya dikemas rapi dalam file ZIP.

Beri metadata lalu unggah

Gunakan ZK Metadata untuk title, deskripsi, dan keyword. Gambar dan video sama-sama didukung. Setelah itu unggah ke platform tujuan Anda.

Pertanyaan yang sering masuk

Apakah saya perlu API key sendiri?

Ya, alat memakai API key Gemini milik Anda, dan membuatnya gratis. Saya sediakan video panduan langkah demi langkah. Tonton panduan API key

Bagaimana cara memasang ekstensi?

Ada video panduan untuk pemasangan di komputer maupun HP. Tonton panduan pemasangan

Apakah data dan API key saya aman?

Alat berjalan langsung di browser Anda tanpa server milik kami, jadi API key tidak dikirim ke kami. Tetap jaga API key Anda dan jangan dibagikan ke orang lain.

Apa bedanya versi gratis dan Pro?

Versi gratis memakai iklan dan tetap aman dipakai. ZK Pro bebas iklan dan menyertakan generate gambar tanpa batas lewat ZK Vector.
